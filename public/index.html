The 3-Tier Fallover Architecture

How ShaastraAI ensures continuous availability even when AWS limits new accounts to 0 tokens/day.

Tier 1
Primary AWS Chain

Amazon Bedrock Converse API

Executes high-parameter reasoning, scanned OCR inspection, and multi-turn query rewriting across native AWS models:

  • us.amazon.nova-pro-v1:0 (High capability & vision)
  • us.amazon.nova-lite-v1:0 (Fast multimodal inference)
  • us.amazon.nova-micro-v1:0 (Ultra-lightweight text)
  • amazon.titan-text-express-v1 (Classic Bedrock base)
AWS SDK Boto3 Streaming Response
Tier 2
Quota-Safe Cloud Fallback

Google Gemini 2.5 Flash

Activated instantly when AWS returns ThrottlingException (common on newly created AWS accounts with 0 initial daily token allowance).

  • Zero payment card needed via Google AI Studio
  • Pure HTTPS REST calls via requests without extra heavy SDKs
  • Full multimodal support for images, text, and documents
  • Seamless fallback transition invisible to the end user

Engineering Highlights

Built for Real-World Scholarship & Data

📜

Dual-Mode Ingestion (Text + Vision)

Standard digital PDFs are vectorized using PyMuPDF and pypdf. Ancient scanned manuscripts with no embedded text layer are automatically detected and analyzed using a 150-DPI high-res vision OCR pipeline.

🔄

Multi-Turn Query Rewriting

When a user asks follow-up questions like *"What did he say about that verse?"*, the system rewrites the prompt into a self-contained search query before querying the FAISS vector index.

🗜️

Multimodal Attachment Compression

Large image or audio payloads in previous turns are compressed into concise semantic summaries, preventing API payload bloat and runaway token costs during long multi-turn sessions.

🎙️

Amazon Transcribe Audio Pipeline

Upload spoken queries in MP3, WAV, M4A, or FLAC. ShaastraAI automatically stages audio in Amazon S3, transcribes speech with Amazon Transcribe, and cleans up temporary buckets.

🎥

OpenCV Video Keyframe Sampler

Long MP4/MOV videos are parsed with OpenCV (cv2) into evenly spaced keyframes, enabling fine-grained visual reasoning without exceeding model context windows.

☁️

Hybrid S3 + Local Storage Sync

Runs seamlessly from local directories (training_pdfs/) or synchronizes automatically with an Amazon S3 bucket on startup.
